## 字体与尺寸
系统字体栈优先使用平台原生中文字体，回退 Noto Sans SC。正文 16px / 1.45，页面标题 22px / 800，子标题 18px，按钮 16px / 700，辅助文字 13px，徽标 11px。

## 组件与交互
- 主按钮 `.pb`：品牌渐变、14px 圆角、轻光晕；按下缩放至 0.97；禁用透明度 40%。
- 次按钮 `.pb.s`：次级表面底色与细边框。
- 幽灵按钮 `.pb.g` / `.lk`：透明底、品牌色文字。
- 危险按钮 `.pb.d`：危险色渐变，不与品牌色混用。
- 图标按钮 `.ib`：44px 触控区域、12px 圆角；按下缩放至 0.9。
- 卡片 16px、输入框 14px、聊天气泡 18px、底部面板顶部 20px。
- 深色和浅色模式保持相同语义映射；VIP 金色为可选覆盖层。
- 保留原主题 58 个画面、214 个控件的覆盖范围，不更改控件动作和状态语义。
