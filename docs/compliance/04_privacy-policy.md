# VEXO 隐私政策


本政策说明 VEXO（下称「本服务」）如何收集、使用、存储、共享和保护你的个人信息，以及你依法享有的权利。请在注册或使用前仔细阅读。本政策与《用户协议》一并构成你与运营者之间关于个人信息处理的约定。

本政策依据《中华人民共和国个人信息保护法》等适用法律法规的常见结构编写，并与当前应用实际收集、使用的数据保持一致。文中以【待填：…】标出的内容，须由运营者核对后填写，不应视为已经确定的法律信息。

## 2. 我们收集哪些信息

我们只收集提供本服务所需要的信息。你未提供或未使用相应功能的，我们不会主动收集该项信息。

**账号与安全。** 注册时的用户名、邮箱、密码（仅以加盐哈希保存，服务器和管理员都看不到明文），以及你同意本政策与《用户协议》的**版本号和同意时间**。登录后会保存会话令牌的哈希、设备说明（根据浏览器或应用的 User-Agent 摘要，例如 iPhone、Android）、原始 User-Agent（截取有限长度）、IP 地址和登录时间。你在「账号安全」中看到的 IP 已经脱敏（例如隐藏尾段）。你还可以修改密码、查看并退出登录设备。

**资料与隐私设置。** 显示名、简介、头像（默认图形或你上传的图片）、主页封面、性别、生日，以及你设置的资料可见范围、是否接受好友申请、是否公开生日 / 年龄 / 性别、是否允许被搜索。主题、语言、界面大小、按键音效和震动等偏好主要保存在本机；你选择的界面皮肤可以同步到账号。

**你发布和交换的内容。** 动态（含可见范围、心情、位置文字、好友标记、话题标签）、评论和楼中楼回复、「日常」限时内容、投票、活动报名、社区与频道消息、群聊和私聊消息、聊天中的图片 / 视频 / 语音 / 文件、草稿、收藏和表情贴纸。一对一私聊在启用端到端加密时，**服务端只保存密文**，无法解密（见第 8 节）。群聊和社区频道消息目前不以端到端加密方式保存。

**位置信息。** 发帖时可以选择「添加位置」。你可以直接输入地点名称；若你点「使用当前位置」，应用会在征得系统权限后读取**大致位置**（关闭高精度，坐标保留约 3 位小数，误差大约 100 米），用于预填地点文字，你可以修改后再发布。发布到服务器的是你确认后的**位置文字**，而不是持续的行踪轨迹。默认不会把坐标发送到第三方逆地理编码服务；只有运营者另行配置了转换地址时，才会用坐标换取地名。我们不读取通讯录，也不在后台持续定位。

**关系与互动。** 关注、好友与好友申请、消息请求、拉黑、个人屏蔽词、在线状态（在线 / 离开 / 隐身；隐身时对外显示为离线）。「正在输入」只通过即时通道短暂推送，**不写入数据库，也不会在重连后重放**。

**端到端加密设备。** 你设备上的公钥和一次性密钥会上传到服务器，以便好友加密发送给你；**私钥只留在你的设备上**，服务端没有、也不能生成你的私钥。

**共创与技能交换。** 你发布的技能交换（「我会什么 / 我想要什么」及分类）、共创项目的目标、技能需求、申请与审核记录、项目群聊、任务、公告和共享资料。

**会员、推流与支付。** VIP 订单和帖子「推流加热」订单信息（套餐、金额、收款方式、你上传的付款截图、处理状态和审核记录）。付款通过微信或支付宝**人工收款码**由你自行转账，本应用**不接入**微信、支付宝等官方支付 SDK，也不在应用内自动扣款。

**举报、申诉与治理。** 你提交的举报对象、理由和说明，以及处理结论；账号申诉的内容和处理结果。管理员对内容或账号作出的处置会留下记录。为识别违规内容，服务端可使用本地屏蔽词，并在运营者配置了密钥时，将相关文本提交给内容审查服务（见第 5 节）。

**日志与审计。** 操作时间、请求路径、部分安全事件（例如限流、登录锁定），以及管理员查看用户或支付等敏感信息时的审计记录。**密码、访问令牌、密钥和私聊明文不会写入日志。**

**本机数据。** 浏览器或应用会在本机保存会话令牌（目前主要在本地存储）、主题与皮肤等偏好、演示数据、图片缓存，以及端到端加密的私钥。与「VEXO 助手」的对话记录只保存在这台设备。演示数据只留在本机，与真实账号分开存放。

我们**不**收集通讯录，也**没有**接入第三方统计分析、广告或社交登录 SDK，也没有接入推送厂商 SDK。

## 3. 我们如何使用这些信息

用于：创建和维护你的账号；提供动态、社区、聊天、好友、媒体、通知、共创和会员等功能；根据你的隐私设置展示资料；处理 VIP 开通、推流加热与退款；内容治理、反滥用（限流、登录锁定、举报处理、必要时的自动或人工审查）和安全保障；回应你的导出、注销、更正和申诉请求；检查和分发应用更新；履行法定义务。不会把你的个人信息出售给第三方。

## 4. 保存期限

在你的账号存续期间，我们保留提供服务所需的数据。数据库会按运营策略做一致性备份（默认保留最近约 14 份快照，具体以运维安排为准）。

你注销账号后：用户名和邮箱会被匿名化，密码作废，所有登录会话失效，VIP 权益取消；你的动态和评论不再对外展示（软删除）；关注、好友、草稿、收藏、屏蔽词以及你的端到端加密设备密钥会被删除；资料显示为已注销。与他人的**聊天密文、已上传的媒体文件、支付和推流订单、审计和举报记录**，可能因对其他用户的对话完整性、财务对账、安全或争议处理而继续保留，你将无法再用原账号登录查看。备份会随后续备份周期被新快照替代。

## 5. 共享、转让与公开披露

我们不会出售你的个人信息，也不会在未经你同意或缺乏合法依据时向第三方转让。以下情形除外：

- **按你的指令展示或发送。** 你公开或按可见范围发布的资料、动态、评论、位置文字、社区和群聊消息，会向相应范围内的其他用户展示；你主动发送的私聊内容会到达接收方（端到端加密时，服务端传递的是密文）。
- **基础设施。** 服务器托管在阿里云。托管方在机房运维范围内可能处理与服务器运行有关的技术数据，运营者不会因此把你的内容另行出售。
- **人工智能服务（按需）。** 当运营者配置了接口密钥时，本服务会调用智谱 AI 开放平台（默认模型为 glm-4-flash，接口位于 open.bigmodel.cn）用于：内容审查、你主动发起的翻译、VEXO 助手问答，以及技能交换匹配。发送的是完成该次请求所需的文本，不含你的密码或端到端加密私钥。未配置密钥时，不会调用该服务，发帖只走本地屏蔽词等规则，助手则回退到本地帮助资料。
- **可选的故障上报。** 客户端内置了与 Sentry 兼容的上报库，**默认关闭**。只有运营者显式开启并配置上报地址（例如自托管的 Bugsink）时，才会发送崩溃或错误信息，且默认不附加可用于直接识别个人的信息（sendDefaultPii 为关闭）。
- **图像处理。** 上传的图片会在服务器上用本地工具（sharp）压缩并去掉 EXIF。运营者可选择开启本地 NSFW 识别（NSFWJS / TensorFlow.js，模型在服务器本地运行，默认关闭）；开启后用于拦截或标记高风险图像，不会把图像发到第三方识别接口。
- **应用更新。** 原生壳使用自托管热更新清单检查和下载更新包（@capgo/capacitor-updater 在设备本地运行）。清单地址由运营者配置，未配置时客户端不会检查或下载。
- **支付工具。** 你使用微信或支付宝扫描运营者提供的收款码时，付款关系发生在你与该支付工具之间；我们只处理你在本服务上传的截图和订单状态，不通过官方支付接口代扣。
- **加密库。** 一对一私聊使用的 vodozemac（Olm）以源代码或编译产物随应用分发，在你的设备上本地运行，不会因此向第三方上报聊天内容。
- **法律要求。** 在有权机关依法要求时，我们可能在法律允许的范围内提供必要信息。一对一私聊若为端到端加密，我们只能提供服务端保存的密文，无法提供明文。

我们不会因为合并、分立、解散或被宣告破产以外的原因转让个人信息；如发生上述情形，我们将告知你接收方的名称和联系方式，并要求接收方继续受本政策约束。我们不会公开披露你的个人信息，法律另有规定或我们获得你单独同意的除外。

## 6. Cookie、会话与本机存储

主要登录方式是请求头中的 Bearer 令牌，保存在本机存储中。可选的浏览器 Cookie 会话（HttpOnly、SameSite）需由运营者另行开启。请不要把令牌放在网址里，也不要在不信任的设备上保持登录。

## 7. 安全措施

密码加盐哈希；数据库访问使用参数化查询；上传校验文件头（魔数）；接口有速率限制和登录失败锁定；管理端敏感读取会记入审计；日志会脱敏。尽管采取这些措施，互联网传输和存储无法保证绝对安全。请尽量在可信网络下使用，并在站点启用 HTTPS 后优先通过加密连接访问。

## 8. 端到端加密的边界

一对一私聊使用 Olm（vodozemac）在设备端加密，服务端只保存密文，不能解密。**群聊和社区频道消息目前不加密。** 密钥备份和多设备恢复尚未提供；撤销登录会话不等于撤销加密设备。你导出数据时，服务端只提供密文；若在本机解密后再保存导出文件，该文件会含明文，请自行妥善保管。独立的安全审查尚未完成。Web 客户端脚本由服务器下发，若脚本被替换，可能在加密前取走明文。请妥善保管本机密钥。
