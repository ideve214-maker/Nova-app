# NOVA V5 项目计划与项目表

> 状态标注规则：**已验证**＝我在本环境用无头浏览器真实跑过；**未验证**＝代码写了但没在真机上试过；**未实现**＝没做。

## 0. 为什么重做 V5（审计结论）
- Grok 生成的 `v5.zip`（React/TanStack 模块化工程）**无法构建**：源码目录写成 `scr/`（配置要求 `src/`）、缺 `scripts/`、`server/`、`migrations/`、`public/`、认证 provider 等。`server/lib/migrations` 之类从未接入。结论：**不修它**，不在它上面继续堆功能。
- 真正能用的是单文件 `nova_v5.html`（Grok 原版）和它的衍生 `NOVA_V6_Preview.html`（另一位 AI 加了转场动画/音效/震动开关）。两者逻辑几乎一致（diff 仅 80 行，全是转场与反馈）。
- **决定**：以 V6 预览（含动画）为基线，拆成 `src/` 多文件 + `scripts/build.mjs` 构建回单文件，所有新功能叠加在上面，品牌与版本统一叫 **NOVA V5**（你要求的"制作 V5 app"）。
- 仍是**本地演示版**：无账号、无后端、无真实加密、无真实推送。聊天页保留"演示模式·未加密"标识。

## 2. 每个里程碑的测试与回退
- 测试：`node tests/run.js`（Playwright 无头 Chromium；每项真点击）。每个里程碑只增不删用例。
- 回退：`git checkout v5.N.0`（N=里程碑号）；或直接解压上一个里程碑的 ZIP。不改写已打标签的历史。

## 3. 风险
| 风险 | 影响 | 应对 |
|---|---|---|
| iPhone Safari 无 `navigator.vibrate` | 震动不一定有 | 用 iOS 18 的 `<input switch>` 触觉技巧，**未验证**，设置页会诚实提示；失败静默降级 |
| iOS 静音键会静音网页音效 | 听不到点击声 | 文档说明；不影响功能 |
| localStorage 约 5MB | 存图会爆 | 图片放 IndexedDB 并压缩；失败提示且不丢文字数据 |
| 动画掉帧 | 卡顿 | 只用 transform/opacity；动画结束清理节点；有"减少动态效果" |
| 单文件体积增长 | 维护难 | src 分段 + 构建脚本 |
