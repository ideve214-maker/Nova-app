# 演示数据与真实账号怎么并存（M2.2）

打开 NOVA 时先看是不是从服务器打开的。

| 情况 | 进哪里 |
|---|---|
| 双击本地 HTML，或服务器连不上 | 直接进演示。不弹登录，旧的自动化测试也靠这个。 |
| 服务器在，而且这台设备存过登录令牌 | 用令牌问 `/api/me`。还有效就直接进账号；刷新、关掉再开也还在。 |
| 服务器在，没有令牌 | 先看见登录/注册。没有底栏，不能先翻动态。 |
| 登录页点「先用演示看看」 | 进演示。演示和账号各存各的。 |

存储键：

- 演示：`nova_v5`（仍能读旧的 `nova_v6` / `v4` / `v3`）
- 某个真实账号：`nova_v5_u_<用户id>`
- 令牌：`nova_session`（只存令牌本身；服务器只存它的 SHA-256）
- 上次选的是演示还是账号：`nova_mode`

切换时先把当前这份存好，再读另一份。退出登录会删掉本机令牌，并通知服务器作废。不会删掉那份本机动态，下次登录同一账号还在。重置也只清当前这一份。

现在动态、社区、聊天都还在浏览器里，没有进数据库。数据库里有的是账号、密码哈希、会话和审计。密码哈希不可还原。

聊天页：演示写「演示模式 · 未加密」；已登录写「已登录 · 私聊尚未加密」。私聊加密留到 M4.11，在那之前不假装已经加密。
