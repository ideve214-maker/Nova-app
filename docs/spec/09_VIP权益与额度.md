## 到期规则
- 到期后由服务端立即按 Basic 处理，没有宽限期。
- 已创建的内容和数据一律保留；到期只失去「新增 / 使用」该权益的能力。
- 距到期不足 3 天时状态为 `expiring`（仅用于提醒，权益仍有效）。
- 开发环境「测试 VIP」一次授予 30 天（仅 `NOVA_ENV=development`）。
