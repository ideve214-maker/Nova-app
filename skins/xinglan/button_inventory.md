# NOVA 用户端控件清单（主题提案用）

- **来源**：`/workspace/nova/src/NOVA_V7`（复制于 `/workspace/nova-theme/NOVA_V7`，未改原仓库）
- **版本**：`0.7.0-m5.1`（`package.json`），Git 最新提交 `M5.4.4 数据导出`
- **技术栈**：原生 HTML/CSS/JS 单页移动端应用；`scripts/build.mjs` 把 `src/` 拼成 `dist/nova_v5.html`；后端 Node.js 22+、内置 `http` + `node:sqlite`；无 React/Vue 等框架
- **统计**：主界面与子页面 **23** 个；底部面板 / 裁剪层 **35** 个；合计画面 **58** 个。下列交互控件按画面列出（动态列表只计模板，不按数据条数翻倍）。控件合计 **214** 项。

---

## A. 认证

### A1. 启动页 `boot`
- （无交互，仅「正在连接…」）

### A2. 登录 `gate / login`
- 输入：用户名或邮箱
- 输入：密码
- 主按钮：登录（忙时「登录中…」且禁用）
- 链接按钮：去注册
- 次要按钮：先用演示看看（未禁用演示时）

### A3. 注册 `gate / register`
- 输入：用户名、邮箱、密码、再输入一次
- 主按钮：注册并进入（忙时「注册中…」且禁用）
- 链接按钮：去登录
- 次要按钮：先用演示看看

### A4. 离线 `offline`
- 主按钮：重试

## C. 四个主 Tab

### C1. 首页 `tHome`
- 图标按钮：搜索、通知（可带红点）
- 分段：关注、推荐
- 头像按钮：自己（进「我的」）
- 次要/占位按钮：写点什么
- 图标按钮：发帖（加号）
- 头像按钮：关注的人（横向列表，每人一个）
- 帖子卡片模板（见 §H1）
- 主按钮：加载更多（有分页时）

### C2. 社区列表 `tCm`
- 图标按钮：创建社区
- 分段：已加入、发现
- 输入：搜索社区
- 发现 Tab 额外：邀请码输入 + 主按钮「加入」
- 社区行（整行可点进入）
- 行内按钮：加入 / 已加入
- 左滑操作（已加入）：置顶/取消置顶、静音/取消静音、退出（所有者无退出）
- 左滑操作（发现）：加入

### C3. 聊天列表 `tChat`
- 图标按钮：新建群聊
- 分段：消息、申请（可带数量）
- **消息**
  - 输入：搜索会话
  - 会话行（整行进入会话）
  - 图标按钮：更多
  - 左滑：置顶/取消置顶、静音/取消静音、隐藏、删除（群聊无删除）
  - 文本按钮：已隐藏的会话 n / 收起已隐藏的会话
  - 已隐藏行：点击恢复
- **申请**
  - 主按钮：接受 / 通过
  - 次要按钮：拒绝
  - （已处理项仅展示状态，无按钮）

### C4. 我的 `tMe`
- 覆盖按钮：更换背景、更换头像
- 统计按钮：粉丝、关注（进入名单）
- 主/次要按钮：编辑资料、设置、会员中心
- （他人主页见 D2，含：关注/已关注、私信、好友相关）
- 分段：全部、简介
- 文本按钮：查看全部（关注的人）
- 头像按钮：关注的人
- 按钮：写点什么
- 帖子卡片模板（§H1）

## D. 子页面

### D1. 帖子详情 `post:`
- 图标按钮：更多（帖子菜单）
- 帖子互动：表态、评论（§H1）
- 评论模板：作者头像、赞、回复、删除（自己的）
- 输入：评论
- 图标按钮：发送
- 文本按钮：取消（退出回复模式）

### D2. 用户主页 `user:`
- 与「我的」结构相近，操作区换为：
  - 按钮：关注 / 已关注
  - 按钮：私信
  - 好友按钮组（§H2）
  - 安全按钮：举报、拉黑 / 取消拉黑（§H3）
- 分段：全部、简介；帖子卡片

### D3. 关注 / 粉丝名单 `fl:`
- 用户行（进主页）
- 按钮：关注 / 已关注

### D4. 编辑资料 `edit`
- 颜色按钮：头像颜色（若干色板）
- 输入：头像上的字（1 字）
- 按钮：用这个字
- 输入：显示名、简介、生日
- 分段按钮：性别（含「不填」）
- 开关按钮：生日 / 年龄 / 性别可见性（公开 / 仅自己）
- 主按钮：保存

### D5. 设置 `set`
- 主/次要按钮：退出、切换（演示）、登录 / 回到账号、重试（离线）
- 行按钮：好友、会员中心、我的收藏
- 分段按钮：深色、浅色
- 开关按钮：减少动态效果、按键音效、按键震动（已开启 / 已关闭）
- 次要按钮：试一下（手感）
- 行按钮：隐私、账号安全
- 危险按钮：重置（先弹出确认）

### D6. 会员中心 `vip`
- 主题预览卡按钮：香槟金、默认（含「使用」态）
- 套餐卡主按钮：开通 {套餐名}
- 付款方式按钮：各收款渠道（微信 / 支付宝等）
- 文件输入：付款截图
- 主按钮：我已付款
- 次要按钮：刷新订单状态、关闭、取消
- 主按钮：重试（读取失败）
- 测试开关（仅开发环境）：切回普通模式 / 切换到 VIP（测试）
- 链接：查看全部、编辑资料（预览卡内）

### D7. 隐私 `priv`
- 分段选择：谁可以看我的资料（所有人 / 仅好友 / 仅自己）等多项
- 开关：已开启 / 已关闭（好友申请等）

### D8. 账号安全 `sec`
- 输入：当前密码、新密码、再输入一次
- 主按钮：修改密码
- 设备行按钮：退出（非本机）
- 危险按钮：退出其他 N 台设备
- 加密设备按钮：撤销
- 主按钮：导出我的数据

### D9. 好友 `friends`
- 分段区域：待处理申请、我发出的、我的好友
- 按钮：通过申请、拒绝、取消申请、删除好友、私信

### D10. 我的收藏 `saved`
- 条目点击（进帖子 / 会话）
- 按钮：取消收藏

### D11. 社区详情 `cm:`
- 覆盖按钮：更换封面（所有者/管理员）
- 主按钮：加入
- 危险按钮：解散社区（所有者） / 退出
- 行按钮：成员、邀请
- 频道芯片：各频道（文字 / 公告）
- 按钮：＋ 新频道、⚙ 管理（有权限时）
- 置顶栏按钮：跳到置顶消息（轮换）
- 消息气泡（点击出菜单）
- 输入栏（§H4）

### D12. 社区成员 `cmm:`
- 成员行
- 按钮：管理（改角色 / 移出）

### D13. 群聊信息 `gi:`
- 按钮：修改群名、更换群头像
- 成员行
- 按钮：＋ 添加成员、管理（设管理员 / 移出）、退出群聊

### D14. 会话 `chat:`
- 图标按钮：更多（私聊菜单）或群聊信息
- 链接按钮：查看安全号码（私聊 E2EE）
- 置顶栏：跳到置顶消息
- 消息气泡：点击出菜单；表情反应芯片（可再点）
- 引用条：取消回复、跳到原消息
- 输入栏（§H4）
- 「对方正在输入…」提示（非控件）

### D15. 通用资料页 `pInfo`（兜底）
- 返回
