# NOVA V7 总项目表（含全部子步骤）

> 给任何接手的 AI：**从上往下找第一个状态不是 ✅ 的步骤，从它开始做。** 每步结束必须：①跑测试 ②更新本表状态与 CHANGELOG ③git 提交 ④打包 `NOVA_V7_{步骤号}_{日期}.zip`（包含整个项目）。每步目标控制在 10 分钟以内，超过就继续拆。
> 基线：本仓库 = 负责人固定的 `NOVA_V5_M4`（前端，模块化 src → 构建为单 HTML）+ 新增 `server/`（后端）+ `apps/admin`（管理端）。沟通一律中文。
> 技术约定（已验证本环境可运行）：后端 Node 22 零依赖（内置 http / node:sqlite / crypto.scrypt）；密码用 scrypt 加盐哈希；登录令牌只存 SHA-256；前端与管理端都是单文件 HTML，通过同一套 `/api/*` 通信。聊天实时先用 SSE（服务端推送）+ POST；有网络安装依赖后再升级 WebSocket（见 M4.9）。
> 沿用安全红线：不存可还原密码；管理员不能看原始密码，只能重置；邮箱默认脱敏、完整查看写审计；管理员邀请码+二步验证；密钥只放环境变量。支付只留空占位，不接。

## 已决定（2026-11-11，负责人确认，不再当成待定）
1. **先给自己和朋友用。** 做法是可迁移的（数据在 SQLite 文件里，不绑死某一家云）。现在不做公开上架，也不做大陆备案流程；如果以后要公开给大陆用户，M6.4 仍要请专业人士核实。
2. **帖子可以带照片和视频。** 实际上传在 M4.5，在那之前按钮不能假装已经发出去。
3. **做双向好友**，不只做单向关注。好友流程在 M4.10。
4. **私聊要端到端加密。** 用成熟协议库，不自己发明算法；库还没接上之前，界面写明未加密。群聊这一版不承诺端到端加密。
